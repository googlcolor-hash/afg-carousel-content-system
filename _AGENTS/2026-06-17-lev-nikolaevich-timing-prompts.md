# Лев Николаевич - тайминг и 7 промптов

Задача: собрать три схемы деления речи по таймингу и полный рабочий вариант на 7 промптов с речью, жестами, ногами и статичной камерой.

Вывод:
- создан файл `outputs/lev-nikolaevich-storyboards/lev-nikolaevich-timing-schemes-and-7-prompts.md`;
- сравнил схемы `3x15`, `8x5`, `5x8`;
- рекомендовал рабочий тестовый вариант на 7 промптов с переменным таймингом около 45 секунд;
- в каждый промпт добавлен жесткий замок статичной камеры;
- маршрут зафиксирован как `1/7 -> 2 -> 3 -> 4 -> 5 -> 6 -> 1/7`;
- учтены правки: точка `7` совпадает с `1`, точки `3` и `6` смещены чуть правее.

Риски:
- схема `8x5` слишком короткая для двух длинных фраз;
- схема `3x15` может хуже держать точный жест и позицию;
- для первых тестов лучше проверять либо `5x8`, либо 7 промптов с переменным таймингом.
