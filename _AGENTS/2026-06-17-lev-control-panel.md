# Лев Николаевич - HTML control panel

Задача: собрать удобную HTML-панель с вкладками и сворачиваемыми блоками для всех материалов по Льву.

Сделано:
- создан `outputs/lev-nikolaevich-storyboards/lev-nikolaevich-prompt-control-panel.html`;
- добавлены вкладки: обзор, движение и ноги, раскадровки, 7 промптов, Seedance 2, зафиксированные промпты, исходники;
- добавлены кнопки копирования для рабочих промптов;
- включены изображения раскадровок и карты движения;
- собраны материалы из текущего чата и локальных файлов production pack / timing / voice / speech.

Риски:
- `navigator.clipboard` на `file://` может быть ограничен браузером; добавлен fallback с выделением текста.
- Если появятся новые промпты из другого чата, их надо добавить в раздел "Зафиксированные промпты".
