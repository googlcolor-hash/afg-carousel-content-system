# Export Plan

## Sizes

- instagram: carousel 1080x1350; video 1080x1920
- linkedin: carousel 1080x1350 PDF; video 1080x1920

## File Types

- Static slides: PNG or JPG.
- LinkedIn document post: PDF assembled from ordered slides.
- Vertical video: MP4, H.264, AAC audio, 24-30 fps unless platform or editor requires otherwise.
- Thumbnail/cover: PNG or JPG.

## Filename Convention

- Slides: `codex_{platform}_{variant}_slide-01.png`
- LinkedIn PDF: `codex_linkedin_{variant}.pdf`
- Video: `codex_{platform}_{variant}_vertical.mp4`
- Thumbnail: `codex_{platform}_{variant}_cover.png`
