# Plugin Workflow

## Что уже сделано

- Miro: доска просмотрена через web/browser-доступ и Accessible Board Overview.
- Social Carousel Factory: структура превращена в production pack.

## Как подключать плагины дальше

### Creative Production

Использовать для генерации 2-3 визуальных направлений по `visual-concept.md`:

- Editorial Science
- Inner Architecture
- Human Scale

Результат: moodboard, visual prompts, варианты обложки.

### Canva

Использовать для сборки редактируемого макета:

- 8 слайдов `1080x1350`
- единая сетка
- экспорт PNG/PDF
- адаптация под stories/reels

### Picsart

Использовать для правки изображений:

- кадрирование Harvard image
- цветокоррекция
- удаление лишних деталей
- приведение ассетов к общей палитре

### BioRender

Подключить при решении делать точную научную схему:

- костная ткань
- костный мозг
- принцип нагрузки
- адаптационный ответ организма

### NVIDIA

Подключать только при необходимости тяжелой визуализации:

- 3D bone/spine render
- Omniverse scene
- GPU-rendered simulation
- inference pipeline for generated assets

Для текущей статичной карусели NVIDIA не обязательна.
