# Canva Handoff

## Документ

- Тип: Instagram portrait carousel.
- Размер: `1080x1350`.
- Страниц: 8.
- Экспорт: PNG для Instagram, PDF для LinkedIn.

## Стили

| Стиль | Размер | Назначение |
|---|---:|---|
| H1 | 74-92 px | главный заголовок слайда |
| Subtitle | 34-42 px | короткое объяснение |
| Caption | 22-26 px | подписи вроде Harvard / Berlin / ISS |
| Source note | 18-22 px | аккуратные пометки источников |

## Сетка

- Поля: 84 px по краям.
- Верхняя служебная строка: номер слайда + короткая метка.
- Зона изображения: 45-55% слайда.
- Зона текста: 35-45% слайда.
- Не ставить больше 2 текстовых уровней на один слайд.

## Порядок сборки

1. Создать мастер-страницу с фоном, номером слайда и текстовой сеткой.
2. Собрать слайды 1-3 в route `Editorial Science`.
3. Собрать слайд 4 и 7 в route `Inner Architecture`.
4. Собрать слайды 5-6 в route `Human Scale`.
5. Проверить читаемость на мобильном размере.
6. Экспортировать PNG и LinkedIn PDF.

## Что отправить в Picsart

- Harvard visual: crop, muted color, remove visual noise.
- Congress visual: warm color grading.
- Bone/spine visual: premium stylization.
- Astronaut visual: match palette and reduce distraction.
